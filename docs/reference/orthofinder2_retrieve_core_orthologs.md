# Retrieve core orthologs across multiple species from Orthofinder2 output

Retrieve core orthologs (= single copy orthologs) across multiple
species from a Orthofinder2 output.

## Usage

``` r
orthofinder2_retrieve_core_orthologs(orthogroups_file, single_copy_file)
```

## Arguments

- orthogroups_file:

  file path to Orthofinder2 output file named `Orthogroups.csv`.

- single_copy_file:

  file path to Orthofinder2 output file named
  `SingleCopyOrthogroups.txt`.
